**要是能更接近 AZ 心中所描绘的密阿雷市……**

和上次《宝可梦 朱／紫 零之密宝》一样，我作为一个策划，又忍不住跑去凑作曲的热闹了。真的非常感谢大家，将我那些粗制滥造的音乐数据通过编曲变成了非常棒的成果！

在《传说 Z-A》终盘的 **《决战！超大失控的昂主花叶蒂》_3.17_**，是以“AZ 的回忆走马灯”为主题制作的。在远处守望着主人公们战斗的 AZ，大概也想起了 3000 年前战争的光景、想起了当时的昂主。所以在曲子的最后，有一段密阿雷市的旋律，这是为了表现一个强调了“美丽”的、理想中的城市。

> “美丽”也是《X／Y》的主题之一。

回过神来，眼前的城市却变得狂野，但哪怕只是一点点，有没有更接近 AZ 心中所描绘的那个城市呢……
