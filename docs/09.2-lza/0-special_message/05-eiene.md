**为5年后的密阿雷市注入生机，是我得到的宝贵经验！**

能够参与到这个作品里去，我从心底感到光荣！我从小就是宝可梦音乐的大粉丝，旋律和节奏早就深深刻进了我的 DNA 里，正因如此，我就一直都想要把这次的工作做到最好。

**《密阿雷市》_xy-1.37_** 是景山将太先生创作的非常优美的曲子，这次我将 49 秒的原曲扩展成约 **4 分钟长的爵士改编 _1.04 4.22 4.23 4.24 4.25_**，并且用了 5 种乐器来区分城市的不同区域。为《X／Y》 5 年后的密阿雷市注入生机，对我来说是一次意义重大的经验！另外，我也在曲中放入了 **《X／Y》标题曲 _xy-1.01_** 的动机，以同时表现城市的发展、以及其让人怀旧的一面。还有 **《密阿雷市 (夜)》_2.01_**，我自己听着也会不禁舞起来了！

> 这里的时长指的是曲子一次 loop 的时间长度。

能够贡献我的音乐，还有萨克斯等乐器的演奏，我真的感到非常的幸福！大家能喜欢我的作品是我的荣幸！
