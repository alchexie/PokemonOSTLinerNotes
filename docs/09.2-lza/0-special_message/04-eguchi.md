**为了音乐能配得上由紫大人而反复试错！**

大家好，我是《战斗！由紫》的作曲者兼《战斗！新闪焰队》《战斗！弗拉达利》编曲者江口！

先说 **《战斗！由紫》_2.27_** 这首曲子，为了能够呈现那种奢华优雅的战斗氛围，我可是不断反复尝试摸索的。我希望战况无论处在何种局面音乐都能将气氛调动起来，所以往曲子里塞满了各种展开桥段。想当初临近完成时，还觉得“音乐不够强势的话可能配不上由紫大人啊……”，然后又急忙重做了一版。由紫大人，不知道您是否满意呢……？

接着说因为太经典而编曲困难的 **《战斗！新闪焰队》和《战斗！弗拉达利》_3.06 3.27_**。无论哪一首都太出名了，也承载着很多人的情怀，让我来负责改编真的没问题吗？压力大呀！于是我也下定决心，在尊重原曲的同时，将当中很“癫”的部分改编成充满希望的感觉。希望大家都能喜欢！
